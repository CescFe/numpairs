# Delivery Documentation

This directory describes how contributors plan, implement, validate, review, and deliver NumPairs
changes. Consult the document that matches the current task; routine work does not require reading
the entire set.

| Task | Document |
| --- | --- |
| Define an issue and its delivery context | [Planning](planning.md) |
| Implement an issue on a branch | [Implementation](implementation.md) |
| Choose and run validation | [Validation](validation.md) |
| Prepare or merge a Pull Request | [Pull Requests](pull-requests.md) |
| Coordinate dependent issues | [Multi-issue delivery](multi-issue-delivery.md) |
| Close a milestone | [Milestone completion](milestone-completion.md) |

These documents complement the relevant product requirements, [game rules](../../game-rules.md),
[ubiquitous language](../../ubiquitous-language.md), code quality guidance, persistence
documentation, and ADRs.
